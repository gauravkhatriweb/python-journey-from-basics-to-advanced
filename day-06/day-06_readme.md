Today I completed Day 06 of my Python learning journey.

## What I Learned

### Loops
I learned that loops are used to repeat a block of code until a condition is met.

Python has two main loop types:

- `for` loops
- `while` loops

### For Loop
I learned how to use `for` loops to iterate over:

- Lists
- Strings
- Ranges
- Other iterable objects

### While Loop
I learned how to use `while` loops to repeat code as long as a condition remains true.

### Nested Loops
I also learned about nested loops, where one loop runs inside another loop.  
This is useful for working with multi-dimensional data like matrices.

### Loop Control Statements
I practiced loop control statements such as:

- `break`
- `continue`
- `pass`

These help control the flow of a loop.

## Key Takeaways

- `for` loops are best when the number of iterations is known.
- `while` loops are useful when the number of repetitions is unknown.
- Nested loops help handle complex data structures.
- `break`, `continue`, and `pass` are useful for controlling loop behavior.
- Loop practice is very important for building problem-solving skills.
