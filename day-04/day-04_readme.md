## What I Learned

### Output
I learned how to display messages on the screen using `print()`.

### Input
I learned how to take input from the user using `input()` and convert it into an integer with `int()`.

### String Formatting
I practiced using f-strings to print values in a clean and readable way.

### Operators
I learned and practiced different Python operators:

- `=` Assignment operator
- `+` Addition operator
- `-` Subtraction operator
- `*` Multiplication operator
- `/` Division operator
- `%` Modulus operator
- `**` Exponentiation operator
- `//` Floor division operator

### Comparison Operators
I also used comparison operators to check conditions like:

- Whether the user is an adult
- Whether the user is a senior
- Whether the user is a teenager
- Whether the user is a child

### Logical Operators
I practiced logical conditions using:

- `and`
- `or`
- `not`

- `input()` is used to get user data.
- Type conversion is important when working with input.
- Operators allow us to perform calculations and comparisons.
- Logical conditions help programs make decisions.
