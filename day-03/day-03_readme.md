# Day 03 - Data Types, Strings & Type Conversion

Today I completed Day 03 of my Python learning journey.

## What I Learned

### Data Types
I learned about the built-in Python data types, including:

- `int` for whole numbers
- `float` for decimal numbers
- `str` for text
- `bool` for True/False values
- `list` for ordered collections
- `tuple` for fixed collections
- `dict` for key-value pairs
- `set` for unique items

I also learned how to use the `type()` function to check the data type of a variable.

### Strings
I learned that strings are sequences of characters enclosed in quotes.

I practiced:
- Single quotes
- Double quotes
- Triple quotes
- Converting other values into strings using `str()`

### Type Conversion
I learned how to convert values from one data type to another using:

- `int()`
- `float()`
- `str()`
- `bool()`
- `list()`
- `tuple()`
- `dict()`
- `set()`

### Indexing and Slicing
I also learned how to work with strings using:

- Indexing
- Negative indexing
- Slicing
- Start and end positions
- Omitting start or end values when slicing

## Practice Done

Today I practiced:
- Identifying different Python data types
- Printing variable types with `type()`
- Converting values between data types
- Accessing string characters using indexing
- Extracting parts of a string using slicing

## Key Takeaways

- Python has many useful built-in data types.
- Strings are very flexible and can be accessed in different ways.
- Type conversion is important when working with user input and different values.
- Indexing and slicing help me work with text more effectively.
